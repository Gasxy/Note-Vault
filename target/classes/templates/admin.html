Welcome, admin

You have administrative access to the Note Vault. From here you can manage all notes and users.

Admin REST Endpoints

Authenticated with HTTP Basic as admin / admin123:

GET    /api/notes          # list all notes (admin sees everything)
POST   /api/notes          # create a new note
DELETE /api/notes/{id}     # delete any note

Example with curl:

curl -u admin:admin123 http://localhost:8080/api/notes
curl -u admin:admin123 -X POST http://localhost:8080/api/notes \
     -H "Content-Type: application/json" \
     -d "{\"title\":\"From API\",\"content\":\"Hello\"}"
curl -u admin:admin123 -X DELETE http://localhost:8080/api/notes/1
